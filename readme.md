To run the main 2D training loop, run main.py directly. You can control the image and budget we train on by modifying the top constants. When the training loop is ran, a PSNR vs N graph is also automatically generated. To change densification parameters, go to densification.py.

To run the main 3D training loop, run main_3d.py. Again, you can change the settings at the top. An important one is whether "NEW_ORBIT" is True. When it is, then we render the translation novel view in addition to the normal validation and training images. Additionally, when "RENDER_TRAIN_VAL" is False, we will not re-render any of the validation or training images (or print their performance). At the top of fit_3d.py, you can change the training parameters. If you set "DENSIFY" to False, then there is no densification. To change the densification parameters, go to densification_3d.py.
